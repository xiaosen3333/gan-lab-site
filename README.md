# GAN lab 网站预览

AI、人机交互与传统文化。原生 HTML、CSS、JavaScript 静态站点，通过 GitHub Pages 从 main 分支根目录发布。

## 使用

不需要构建或安装依赖。可直接用静态服务器打开目录，例如 `python3 -m http.server 8766`。页面采用 hash 路由，支持 GitHub Pages 项目路径。

网站保留预览标识和 noindex。老师无需登录或填写网页表单：团队提供已有材料与修改意见，由 AI 整理内容、调整布局并维护静态页面。旧管理和草稿预览地址回到首页；站内不提供内容管理演示。

三项精选研究在 `research.js` 中维护，成员名录在 `team.js`，扩展论文与成员关联在 `publications.js`；页面结构在 `app.js` 与 `index.html`，样式在 `styles.css`。团队页采用纯文字介绍，不设置照片、头像或图片占位。更新前核对材料事实与图片使用范围，更新后检查桌面、手机和相关链接。原始内部材料不进入公开仓库。

## 内容来源

导师与研究资料整理自[李泽健个人主页](https://zejianli.github.io/markdown/2024/06/02/About-me.html)、[浙大教师主页](https://person.zju.edu.cn/zejianli)及各研究的官方论文/学院页面；原文地址保留在数据中，当前论文目录隐藏外链按钮。成员名单与学位Title由团队确认；公开来源另行核验，不把合作者自动认定为组员。研究数量只统计当前收录的成员关联论文与预印本，不作为个人全部发表量；研究概述由这些作品的内容归纳；以“参与”说明共同研究，不推断个人具体分工。个人学术背景与荣誉由院校或本人原始页面核验，来源链接保留在成员数据。当前收录31位成员、28篇论文与预印本；资料不足的成员保留团队确认身份。成果保留扩展摘要、已接收工作与预印本的必要标注；撤稿记录不作为论文荣誉。

## 成员与论文的阅读层级

名录只显示中文姓名与Title，点击姓名进入 `#/people/成员id`；个人页先呈现介绍、当前收录研究的概述，再列论文标题与年份/会议。可用的个人主页和浙大主页只放在个人页。没有论文数据的成员不会被填入假数字、研究兴趣或空论文区。旧 `#/outputs?member=...` 与 `#/people?member=...` 地址兼容进入个人页，返回名录会定位原成员。

`app.js` 中的 `presentation` 开关控制英文姓名、分类按钮、论文摘要、参与者、附属按钮和标题链接，当前均为 `false`。数据、链接和相应渲染代码均保留；如需恢复，按具体展示需要打开对应开关并重新验收。关闭分类时，旧 `type` 参数不会悄悄限制显示内容。

首页图片为原创 AI 生成概念视觉，不是实际古画、修复结果或实验数据。仓库不包含内部研究资料、设计过程记录或旧版稿。
