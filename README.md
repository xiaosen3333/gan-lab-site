# GAN lab 网站预览

AI、人机交互与传统文化。原生 HTML、CSS、JavaScript 静态站点，通过 GitHub Pages 从 main 分支根目录发布。

## 使用

不需要构建或安装依赖。可直接用静态服务器打开目录，例如 `python3 -m http.server 8766`。页面采用 hash 路由，支持 GitHub Pages 项目路径。

网站保留预览标识和 noindex。老师无需登录或填写网页表单：团队提供已有材料与修改意见，由 AI 整理内容、调整布局并维护静态页面。旧管理和草稿预览地址回到首页；站内不提供内容管理演示。

公开资料在 `research.js` 中维护，页面结构在 `app.js` 与 `index.html`，样式在 `styles.css`。更新前核对材料事实与图片使用范围，更新后检查桌面、手机和相关链接。原始内部材料不进入公开仓库。

## 内容来源

导师与研究资料整理自[李泽健个人主页](https://zejianli.github.io/markdown/2024/06/02/About-me.html)、[浙大教师主页](https://person.zju.edu.cn/zejianli)及各研究的官方论文/学院页面；网站中保留原文入口。精选工作标明为导师参与的研究，不把合作者自动认定为实验室成员。

首页图片为原创 AI 生成概念视觉，不是实际古画、修复结果或实验数据。仓库不包含内部研究资料、设计过程记录或旧版稿。
